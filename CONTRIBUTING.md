# Contributing

Thank you for your interest in contributing to this project! This document explains how the repository is protected and how you can submit changes.

## Branch Protection

The `main` branch is protected with the following rules:

- **No direct pushes** -- All changes must be submitted via a pull request. Pushing directly to `main` is blocked for everyone, including administrators.
- **No force pushes** -- Force-pushing to `main` is not allowed.
- **No branch deletion** -- The `main` branch cannot be deleted.
- **No bypass** -- These rules apply to all users, including repository administrators.

## How to Contribute

1. **Fork the repository** -- Create a personal fork on GitHub.
2. **Create a branch** -- Work on a descriptive feature or fix branch (e.g. `feat/add-about-page`, `fix/broken-link`).
3. **Make your changes** -- Commit your work to your branch.
4. **Open a pull request** -- Submit a PR against `main` with a clear description of what you changed and why.
5. **Review** -- The repository owner will review your PR and provide feedback or merge it.

## Guidelines

- Keep pull requests focused and small when possible.
- Write clear commit messages that explain the "why" behind a change.
- Test your changes locally before submitting.
